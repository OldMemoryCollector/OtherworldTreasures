# 异次元乱入（OtherworldTreasures）

《杀戮尖塔2》自定义模组。本模组完全由AI制作，图片来自官方网站、百科网站、GPT图片生成等。

本模组添加了**十件先古遗物**，以及多个先古遗物的附属遗物。

## 1.不死人的原素瓶——来自《黑暗之魂》

**效果**：移除一个药水栏。右键点击遗物恢复15%最大生命值，可使用2次。篝火处注火可提升1点上限并回复所有次数。击败精英或Boss后有50%几率补充1次使用次数。（当该遗物被移除后，会增加一个药水栏）

## 2.惊奇套牌——来自《炉石传说》

**效果**：战斗开始时，将5张【惊奇卡牌】洗入你的牌库。

- **惊奇卡牌**：抽到时立刻施放。抽一张牌。打出一张套牌外的随机卡牌并将其除外。（随机范围：不会生成诅咒、状态、任务、事件、先古与衍生卡牌。）

## 3.库拉的骰子——来自《摩尔庄园》

**效果**：每次战斗开始随机骰出1至6点。右键点击遗物发动当前点数对应的能力。每个点数的能力仅限使用一次，发动6点后遗物永久失效。

- **一点恢复**：休息1次；获得10点【再生】（会触发小邮箱等遗物联动）。
- **二点复制**：本场战斗中所有卡牌获得1层【重放】。
- **三点强化**：本回合造成的伤害与获得的格挡变为3倍，并获得3点能量。
- **四点结界**：本场战斗中获得8层【缓冲】、8层【无实体】和8层【人工制品】。
- **五点爆炸**：对每个敌人造成联机人数次300点伤害（无视格挡，逐次独立结算）。
- **六点实现愿望**：获得999金币；恢复全部生命值；升级所有卡牌；获得6件遗物；该遗物永久失效。

## 4.戴夫的种子——来自《植物大战僵尸》

**效果**：可以召唤向日葵、豌豆射手、坚果墙三种植物中的一种，它会像奥斯提一样优先承受伤害，而且伤害溢出后多余的伤害不会到玩家身上，每场战斗可以召唤一种植物。不同的植物有不同的效果。

**承伤顺序**：坚果墙>奥斯提>向日葵/豌豆射手>玩家

- **向日葵**：血量15，在场时每回合开始为你提供1点能量，召唤当场就会给1点，有概率获得2点。
- **豌豆射手**：血量20，在场时每回合开始时对前方的第一位敌人造成7点伤害，有概率攻击两次。
- **坚果墙**：血量25，在场时每回合开始获得6点格挡，有概率获得两次格挡。

再次右键点击遗物可获得【施肥】卡牌，为场上的植物提升最大生命值并回复等量生命。

## 5.神话护身符——来自《泰拉瑞亚》

**效果**：战斗开始时获得1层【缓冲】和1层【人工制品】。每回合开始时恢复1点生命值，当前生命值低于上限一半时改为恢复2点。

## 6.孢子囊——来自《泰拉瑞亚》

**效果**：每次受到攻击时，给予攻击者中毒，初始为1层。每赢得3场战斗，层数增加1层；同一场战斗内，从第2回合起，施加的中毒每回合再增加1层。攻击者会显示绿色负面特效；角色身上的"孢子囊"能力实时显示当前回合可反制的层数。

## 7.十字章护身符——来自《泰拉瑞亚》

**效果**：抽到状态牌或诅咒牌时，将其消耗并抽1张牌。回合结束时，消耗手牌中的状态牌与诅咒牌，获得2点格挡。

## 8.哆啦A梦的四次元口袋——来自《哆啦A梦》

**效果**：获得时立即得到一件哆啦A梦的道具。接下来3次从精英战斗获得的遗物，改为来自哆啦A梦的道具。

- **任意门**：右键点击开启自由传送，开启后可直接前往任意未通过的节点。可使用3次，再次右键点击可关闭。开启后地图上所有未通过的节点都会点亮为可前往；未开启时与平时一样。沿地图连线正常移动不会消耗次数，只有直接飞往不相邻的节点时才消耗1次。当剩余最后一次机会时，无法选择终点是已走过的节点的路线。
- **缩小灯**：右键点击获得一张【缩小灯】卡牌，可无限获得。缩小灯卡牌：使敌人缩小（就是原版的缩小效果），无限时长。
- **竹蜻蜓**：战斗开始时起飞，被攻击时受到的伤害减少50%，被攻击5次后失效。和原版的飞行效果一致，即使伤害被格挡次数也会减少。落地10回合后会再次起飞。
- **如果电话亭**：以新的抽卡顺序重新开始本次战斗。
- **时光布**：右键点击获得一张【时光布】卡牌，每场战斗只能获得一张。卡牌效果：可以选择加速或者回溯一个回合，可以对敌人、自身、部分遗物使用，可以改变血量、状态时间、意图、遗物的回合计数等。注意：如果是当前回合使用能力，并对自己使用回溯，会导致能力消失。
- **空气炮**：战斗开始时，将一张1费【碰】卡牌加入手牌。【碰】：对一名敌人造成20点伤害，抽1张牌。
- **桃太郎丸子**：拥有3颗丸子。右键点击后选择一名敌人收服：只能收服当前生命不超过10点、最大生命不超过80的敌人，首领无法收服。收服后回满血、生命上限降低20%，它会保留原本的招式与意图为你作战，造成的伤害减少50%，无法被治疗，死亡后永久消失。

## 9.小破表——来自《Ben 10》

**效果**：战斗内右键点击变身成为外星英雄，每场战斗限变身一次。右键后播放变身动画，随后弹出英雄选择界面，用左右箭头切换、确认后替换角色形象，血条上的角色名字也会变为英雄名。可选英雄为**火焰人**、**四手霸王**、**超能兽**；有极低的概率变身会被**鬼影**替换。变身持续三个回合。

**火焰人**的专属卡牌与被动能力已实现（卡牌均由AI设计，目前仅作测试用，后续会进行调整与重新设计）；其余英雄目前仅替换角色形象。

## 10.四魂之玉——来自《犬夜叉》

**效果**：取得时宝玉因未知原因破碎，化作【四魂之玉碎片】，并使地图上除Boss之外的敌人也带上碎片。右键点击碎片可开启或关闭效果（战斗中不可切换）。

- **开启时**：你按持有的碎片种类获得强化（荒魂提升力量、和魂提升覆甲、幸魂提升再生、奇魂提升生命上限）；地图上出现持有碎片的敌人，击败它们即可夺走其碎片。
- **关闭时**：不获得强化，地图上也不显示这些敌人。
- 效果强度大致相当于一代的【带火精英】；每枚碎片只会分配给一名敌人，但一名敌人可以拥有多枚碎片。
- 碎片图标四角分别显示四种魂的数量。

## 其他内容

### 生命水晶——来自《泰拉瑞亚》

战斗胜利后的奖励中可能出现【生命水晶】，领取使用后生命上限提高10点（同时回复10点生命）。

## 说明

模组已在Steam创意工坊发布，目前仍在测试中，部分数值和效果可能会有调整。有什么想法和建议，欢迎在Issues或工坊评论区沟通。后续应该会考虑更换卡图。

## 后续更新计划

- **平衡性调整**：将提供两种模式可选。
  - **平衡模式**：遗物等设计会比原版先古遗物略强一些，追求与原版相近的难度曲线。
  - **原生模式**：仅基于趣味性设计，即目前的效果，不刻意追求数值平衡。
- **美术资源完善**：后续会将卡图、特效、动画等内容进行完善，使整体风格更加融洽统一。
- **戴夫的种子**：后续会加入更多植物。
- **小破表**：后续会补齐Ben 10原版十个外星英雄的变身，并为每个英雄补充专属卡牌与变身后的能力效果。
