# SCP-294 随机替代或附加药水意图验证（2026-10-21）

“为什么会变成这样呢？（测试中，未完善）”现在每次生成招式预告时，在替代和附加之间各以 50% 概率选择。替代时仅显示及执行药水意图；附加时保留原意图，并增加一个药水意图，先执行药水，再调用原招式一次。状态机的招式完成标记仍会更新。晕眩、睡眠保持原行为。

药水独立生成 0～6 种不同药效，通常强度为普通药水基准的 1～3 倍，每条药效独立随机作用于双方。删除原先“原意图数量乘 2”、原伤害和格挡上限、按幕数与普通/精英/Boss 分类的固定强度，以及不再使用的原生格挡表达式表。灾厄仍单独限制为每瓶 1～10 层。开战鸡尾酒仍单独执行一次，且只有开战药水禁止对玩家直接造成伤害。

0 药效时仍保留药水意图和投瓶，提示显示“无药效”。附加药水使用意图的随机流，新增 IsCombatStart 标记把它与开战鸡尾酒的显示随机流区分开；显示配方仍然缓存，刷新不会重掷。

## 验证

2.4 万份配方抽样，共 264,831 项断言通过，覆盖数量、无重复、基准倍率、灾厄限制、作用对象、开战伤害例外和相同种子的确定性。

隔离原生游戏完成 24 项检查。实际调用 Prepare 生成 300 个招式，附加 149 次、替代 151 次，0～6 种药效分别出现 41、45、40、46、46、42、40 次。验证附加时原意图对象仍保留；原伤害为 0、无格挡数值时仍能生成独立的伤害和格挡效果；同一随机标识下，将 1 个低伤害原意图改为多个高伤害意图，药水配方保持一致。

执行检查覆盖替代时不调用原招式、附加时调用原招式一次、状态机完成标记、零药效附加仍执行原招式、晕眩和睡眠、两种预告的原生图标和完整提示、实际敌方回合返回玩家、与开战鸡尾酒同时生效、两种配方显示随机流的区分。为隔离执行路径，探针中部分药效换成无害格挡；随机数量和强度由上述生成抽样验证。两种预告均已保存并检查实机截图。

主项目构建 0 错误、21 条既有警告；探针构建 0 警告及错误。宿主退出仍有既有资源清理诊断。未执行两个真实客户端的联机验证。
