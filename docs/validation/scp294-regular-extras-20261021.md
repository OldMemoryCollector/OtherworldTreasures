# SCP-294 常规模式附属选项验证（2026-10-21）

“本地酿造厂”“狂乱鸡尾酒”“为什么会变成这样呢？（测试中，未完善）”改为常规模式的附属选项。原“常态模式”中文名称统一为“常规模式”，附属区显示“常规模式附属选项”。界面启用条件和开局规则 Capture 均改用 EverywhereMode，不再依赖 CrazyMode；疯狂模式仍可与常规模式组合开启。

保留已有配置字段 CrazyNeowRelics / CrazyMonsterPotions / CrazyPotionIntents、配置分区 ID 及跑局保存和同步标识，避免已有开关值和保存结构发生不必要变更。附属规则仍在开局捕获，已有跑局沿用保存的规则快照。随机替代或附加药水意图的规则保持不变。

## 验证

覆盖疯狂模式开/关、常规模式开/关和三个附属开关的全部 32 种组合，128 项断言通过。逐项核对开局规则仅等于“常规模式 AND 对应附属开关”，并检查保存编解码。

隔离原生游戏在 CrazyMode=false、EverywhereMode=true 时完成 8 项检查：新局捕获三个附属开关；涅奥显示本地酿造厂单选项；同时获得三件遗物，增加 3 个药水栏并获得 2 瓶药水；怪物开战喝药；怪物生成随机药水意图；敌方回合正常返回玩家。已检查涅奥选项截图。主项目构建 0 错误，21 条既有警告；探针构建 0 警告及错误。退出仍有既有宿主资源清理诊断。未执行双客户端联机实测。
