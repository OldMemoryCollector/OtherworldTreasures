# SCP-294 周期状态清除配置与验证（2026-10-21）

随机药水设置新增“周期状态清除”，依赖常规模式，默认关闭。X 用可填写的文本框输入正整数，提供输入校验；作用对象选择敌方、我方、全体，清除种类选择单项、全部，层数选择 1、2、3、一半、All，状态类型选择正面、负面。配置在开局捕获并包含在已有 RitsuLib 跑局规则和房主快照中，旧存档缺少该字段时保持关闭。

每个完整敌我回合结束后检查一次，第 X、2X、3X……回合执行；用战斗对象和回合号防止重复触发，新战斗重新计数。只处理仍存活的目标。单项为每个目标随机选择一种符合条件的状态，按稳定顺序和独立确定性 RNG 选择，不消费游戏 RNG；全部为该目标当前所有符合条件的状态。

按原生 TypeForCurrentAmount 分类，负力量、负敏捷能识别为负面。层数以绝对值计算并向零减少，不足指定数量时移除整个状态；一半向上取整，无叠层状态视为一层。完整移除使用 PowerCmd.Remove，部分减少使用原生 SetAmount，并刷新敌人意图显示；清除不作为新的减益施加，因此人工制品不会抵消或额外消耗。

回合挂钩只包裹 CombatManager.EndEnemyTurnInternal，等待原生结束钩子完成，检查其所属 CombatTurnState 仍存活后处理该战斗；未修改全局 Hook 分发器。旧保存和同步标识保持不变，新规则使用已有的可扩展 RitsuLib 数据字段。
