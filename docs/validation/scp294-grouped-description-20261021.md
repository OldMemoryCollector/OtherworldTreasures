# SCP-294 同目标药效合并显示（2026-10-21）

玩家与敌人药水共享按目标合并的描述生成器。目标按首次出现的顺序展示，每个目标的药效保留原先相对顺序，中文用分号连接并由原生提示框自动换行；目标名称每组只显示一次。英语与日语同步支持。

截图中的六种药效显示为：

玩家：攻击造成的伤害降低30%，持续4回合；获得6点力量；施加9层虚弱。
自身：获得3层缓冲；获得4点敏捷；获得36点格挡。

单项效果保持原来的句子；不同目标范围（自身、敌方目标、己方全体、敌方全体、敌我双方、自身与敌方目标）不会互相合并。自行明确描述目标的特殊效果（例如双方不同灾厄量、全场泼洒、致命保护）保留完整原句。原版药水本体描述仍在前面，附加效果按上述规则合并。数值、高亮、时机和持续时间保留，保存配方与实际药效执行逻辑不变。

## 验证

主项目构建 0 错误、21 条已有警告；隔离探针构建 0 警告及错误。原生游戏 15 项检查通过：中英日的敌人两组目标标签、数值与持续时间、玩家药水共同分组；格式化前后序列化配方相同；同一药效不同数值保留独立子句；特殊目标句子保留；六种目标范围不混合；实际入栏后原生玩家悬浮提示显示两个目标组。
