# SCP-294 三组状态清除与药水意图概率验证（2026-10-21）

状态类型新增“全部”，包含当前正面与负面状态，保留中性 PowerType.None。负力量等仍按原生当前数值分类。

原作用对象下拉框拆成“敌方状态清除”“我方状态清除”“全体状态清除”三个独立分区，各自拥有开关、正整数回合间隔、单项/全部、1/2/3/一半/All 层数以及正面/负面/全部。依赖常规模式、开局捕获。三组可同时开启，按敌方、我方、全体顺序分别检查和处理，重叠对象会分别承受每组效果。回合去重按组记录，避免第一组阻止其他组，同组随机选择使用独立的目标组标识。

旧单条全局设置在首次读取时迁移到它原先选中的目标组，另外两组保持关闭；迁移标记防止用户关闭新分组后又被旧值重新开启。跑局数据保留旧 StatusPurge 字段，新局使用 StatusPurges 三组数组；读取旧跑局时仍执行原单条规则。已有保存和房主同步标识保持不变。

药水意图概率改为 33% 附加、33% 替换、34% 不变（33% 加剩余 1%）。从 0～99 等概率票号映射出 33/33/34 个结果。“不变”保留原意图与原招式，内部仅缓存本回合选择，实际执行不进入药水处理、不投瓶、不产生药效；再次刷新不重掷。附加与替换的药水生成规则保持不变。

## 验证

纯规则 203 项断言通过：16 种常规模式/三组开关组合及独立值、三种旧目标的迁移、迁移幂等性、旧跑局读取、单组非法输入不影响其他组、保存与房主快照编解码、100 张票的精确 33/33/34 分配和边界。

隔离原版游戏完成 32 项检查，包括三组开局捕获、正负状态一起清除、按阵营隔离、负力量和正力量同时按半数处理、各自间隔、分组去重、真实回合上的叠加结果、关闭组不执行及旧跑局规则回退。测试夹具中敌方每回合减 1、我方每 2 回合减 2、全体每 2 回合减 1；双方 10 层力量在第 2 回合结束后均为 7，验证了独立执行与叠加。

实际调用 Prepare 600 次，附加/替换/不变样本为 212/205/183。有限抽样不是强制配比；精确权重由上述 100 张票检查验证。实机检查三个分支的意图形状、原招式回调次数、仅附加/替换产生药效、状态机完成标记、不变分支缓存以及完整敌方回合。

配置页实际打开三个分区，验证每组都有独立的三选一状态类型，编辑敌方间隔为 7 不改变我方 3、全体 4，再恢复敌方 2；已检查“正面/负面/全部”下拉菜单和“不变”意图的实机截图。测试配置仅在隔离目录修改，完成后恢复。

主项目构建 0 错误、21 条既有警告；探针构建 0 警告及错误。宿主退出仍有既有资源清理诊断。未执行两个真实客户端的联机实测。
