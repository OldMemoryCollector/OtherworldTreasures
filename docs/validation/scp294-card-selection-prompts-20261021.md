# SCP-294 选牌提示修复（2026-10-21）

玩家使用消耗手牌等药效时，原生 PotionModel.SelectionScreenPrompt 根据实际模型 ID 查找 OTHERWORLD_TREASURES_POTION_SCP294_POTION.selectionScreenPrompt；该键缺失，导致界面直接显示完整的 potions.…selectionScreenPrompt 键名。五种药效此前共用这个缺失提示。

改为按药效使用独立提示：抽牌堆选牌、手牌本场免费、任选手牌消耗、弃牌堆取回且本回合免费、任选手牌弃掉再抽等量牌。中英日三种语言各新增五个专用提示，并补齐原生模型 ID 的通用选牌提示作为回退。选择数量、筛选、耗能修改范围和原生同步流程保持原逻辑。
