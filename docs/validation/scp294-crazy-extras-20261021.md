# SCP-294 疯狂模式附属选项验证（2026-10-21）

> 后续规则已调整：意图改为随机替代或附加，药水独立生成并取消幕数和敌人类型强度表。现行规则见 [随机药水意图验证](scp294-random-intent-20261021.md)；下文保留当时的验证记录。

三个开关默认关闭，依赖疯狂模式。开局时捕获设置并随跑局保存；联机由房主提供规则快照。药水配方使用由局种、地图坐标、怪物战斗 ID、回合和招式 ID 派生的独立确定性 RNG，刷新意图不会再次抽取。

- 本地酿造厂：一个选项同时获得白兽雕像、药水腰带、药瓶皮套，保留各遗物的原版获得效果。
- 狂乱鸡尾酒：仅战斗开始时，每个初始敌人使用一瓶随机药水；0～6 种不同效果，强度为原版基准的 1～3 倍，伤害效果只允许指向自己。
- 为什么会变成这样呢？：以一瓶药水替换原招式，效果数是原意图数的 2 倍；伤害和格挡在原招式总值以内取整数，其他效果按普通/精英/Boss、第一幕 2/4/6、第二幕 4/8/16、第三幕 8/16/32。此模式允许伤害药水攻击玩家，并可与开战额外喝药同时开启（初版互相覆盖的问题已修正，见同日 cocktail-random 验证记录）。晕眩和睡眠保持原行为。随机调制药水与两种怪物药水的灾厄均单独限制为每瓶 1～10 层，不使用原版 33 层基准或幕数/Boss 强度。

## 验证

使用编译出的模组 DLL 和游戏自身 RNG 抽样：12,000 个开战配方、18,000 个替换意图配方。检查数量、不同药效、倍率、对玩家直接伤害限制、九档强度、相同种子的配方一致性、主开关限制、规则与房主快照编解码。

隔离的原版游戏进程完成 30 项检查：涅奥单选项同时发放三件遗物、合计增加 3 个药水栏并赠送 2 瓶药水；开战喝药只执行一次且保留原意图；替换意图药效数量；原生魔法骑士格挡值和多段攻击合计值；原招式被抑制、状态机仍能前进；向自己和玩家投瓶的源/目标坐标及显示层级；完整敌方回合返回玩家；连续两瓶最高灾厄合计 20 层，未达到满血玩家的原生斩杀阈值。

构建为 0 错误，21 条既有警告。原生进程退出时仍有宿主资源清理警告；没有出现战斗回合异常。未执行两个真实客户端的联机回归，不能将确定性和编解码检查视为双端联机验证。
