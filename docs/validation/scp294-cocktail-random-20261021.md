# SCP-294 狂乱鸡尾酒触发与随机目标修复（2026-10-21）

> 后续规则已调整：意图改为随机替代或附加，药水独立生成并取消幕数和敌人类型强度表。现行规则见 [随机药水意图验证](scp294-random-intent-20261021.md)；下文保留当时的验证记录。

用户反馈开战药水未触发，且怪物药水总对怪物有利。检查正式配置时，两个附属开关均开启。代码原先在 PotionIntents 开启时直接跳过 CombatStart；Brew 则依据药效正负固定分配对象，增益给怪物，负面给玩家。

删除两开关之间的互斥条件。两个开关同时开启时，每只初始怪物开战使用一次随机药水，随后由药水意图执行它的回合。开战记录保存已使用的配方并防止重复；死亡怪物跳过。开战和意图配方使用不同的确定性 RNG 标识，显示配方同步采用对应标识。

每条药效从可用池等概率抽取后，独立以各 50% 概率作用于怪物或随机选定的玩家，不依据正负效果分配。保留用户指定限制：开战药水的直接伤害仅作用于怪物自己；意图药水的直接伤害可作用于双方。0～6 种不同开战药效、通常强度 1～3 倍、灾厄每瓶 1～10 层及意图总伤害和格挡上限均保留。四种有利或不利方向可以混合出现，并不强制一瓶凑齐。

## 验证

使用游戏原生 RNG，对 12,000 份开战配方和 18,000 份意图配方抽样，合计 569,894 项断言通过。检查效果数量、无重复、倍率、九档幕数和战斗类型强度、伤害格挡范围、灾厄上限、主开关、保存和房主快照编解码，以及相同种子的结果一致性。分布检查采用不同的种子；各可选药效的玩家目标占比为 46.82%～51.89%，开战直接伤害对玩家为 0。0～6 药效数量样本分别为 1718、1715、1737、1696、1742、1650、1742。

隔离原生游戏完成 17 项检查：双开关同时生效、开战只执行一次、随机流分离、完整预览对象；实际向玩家投瓶并给予力量、给怪物自身虚弱；另外验证怪物力量及玩家虚弱；完成敌方回合后返回玩家且不重复开战药水；分别只开启两种选项时的行为。指定力量和虚弱的配方仅用于验证原生效果施用，随机目标分布由上述抽样覆盖。已检查预览及实际状态变化截图。

主项目构建 0 错误，21 条既有警告，测试探针构建 0 警告和错误。宿主启动出现 worker-thread task ID 诊断，退出存在既有 RID 和资源清理诊断；本次行为断言通过。未做两个真实客户端的联机实测。
