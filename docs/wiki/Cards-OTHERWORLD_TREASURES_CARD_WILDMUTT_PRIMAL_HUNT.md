# 原始猎杀

[首页](Home.md) / [卡牌图鉴](Cards.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_CARD_WILDMUTT_PRIMAL_HUNT.webp" width="280" alt="原始猎杀">

**稀有度：**先古　**类型：**攻击　**基础费用：**2　**目标：**自身

## 效果

**保留**。<br>
对**猎物**造成3次5点伤害。<br>
若此牌击杀**猎物**，对新的**猎物**重复上述攻击，最多额外重复2次。<br>
此牌只触发1次**野性追猎**额外攻击。

此牌不能升级。
