## 出现条件

| 项目 | 规则 |
| --- | --- |
| 出现层数 | 第二幕（Hive）的先古之民节点 |
| 出现位置 | 本幕先古之民候选；不是普通问号事件。 |
| 前置条件 | 没有额外的遗物、牌组或金币要求。 |
| 重复限制 | 由本幕先古之民抽选决定，并非每局必定出现。 |

**选项可用条件：**优先排除玩家已经持有的候选遗物，随机提供至多4个选项；若候选全部持有，则退回完整池。

层数按第一、第二、第三幕计算；满足条件表示可以进入候选，不保证本幕一定遇见。

**条件来源：**[MemoryKeeper.cs](https://github.com/OldMemoryCollector/OtherworldTreasures/blob/main/Scripts/Ancients/MemoryKeeper.cs)
