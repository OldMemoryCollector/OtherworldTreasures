## 出现条件

| 项目 | 规则 |
| --- | --- |
| 出现层数 | 仅第二幕 |
| 出现位置 | 普通问号事件，无固定的小楼层或房间序号。 |
| 前置条件 | 本局尚未遇见本事件，且本局尚未遇见先古之民「旧忆收藏家」；无需特定遗物或卡牌。 |
| 重复限制 | 本局至多遇见一次。 |

**选项可用条件：**单人和多人均可出现；元气弹只在多人局进入界王的随机传授结果，不是整个事件的出现前置。

层数按第一、第二、第三幕计算；满足条件表示可以进入候选，不保证本幕一定遇见。

你来到一片陌生的修行场。三位散发着强大气息的身影注意到了你。<br>
<br>
其中一人开口说道：<br>
<br>
「虽然不知道你为什么来到这里，但看你好像需要帮助。我们可以教授你我们的【绝学】。」

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。
