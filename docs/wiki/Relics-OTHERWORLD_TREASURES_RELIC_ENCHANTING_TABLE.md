# 附魔台

[首页](Home.md) / [遗物图鉴](Relics.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_RELIC_ENCHANTING_TABLE.webp" width="96" alt="附魔台">

**稀有度：**先古

## 效果

击败敌人获得其原始最大生命值的六分之一经验，休息处获得15点经验。战斗中右键选择一张牌，消耗1级经验并随机附魔；休息处可消耗5级经验，为一张牌永久附魔并升级。

## 使用说明

战斗内为临时附魔；休息处可以永久附魔并升级。只从适配所选卡牌的附魔中抽取。

## 轶闻

> 经验与魔法在此交织。
