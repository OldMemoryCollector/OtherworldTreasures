# 缩小灯

**稀有度：**99

## 效果

右键点击获得1张**缩小灯**卡牌，可无限获得。

## 轶闻

> 哆啦A梦的道具之一。被光照到的东西会缩小，照得越久缩得越小；想变回原样，得用放大灯。
