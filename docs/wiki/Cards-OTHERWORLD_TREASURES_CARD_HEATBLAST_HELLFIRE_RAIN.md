# 炎狱天降

[首页](Home.md) / [卡牌图鉴](Cards.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_CARD_HEATBLAST_HELLFIRE_RAIN.webp" width="280" alt="炎狱天降">

**稀有度：**先古　**类型：**攻击　**基础费用：**2　**目标：**所有敌人

## 效果

**保留**。<br>
将2张**灼伤**状态牌加入你的**手牌**。<br>
给予所有敌人2层**灼伤**。<br>
**消耗**你**手牌**中的所有状态牌。<br>
对所有敌人造成其**灼伤**层数8倍的伤害。

此牌不能升级。
