# SCP-294：咖啡机

[首页](Home.md) / [事件图鉴](Events.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_EVENT_SCP294.webp" width="800" alt="SCP-294：咖啡机">

一台咖啡机静静地立在这里。投币口旁的标签写着：饮料只需**50金币**。

## 使用方式

- **随机调制 · 50金币**：依次选择口味、感觉和浓度，最终选项直接预览可能获得的产物。
- **自由输入 · 50金币**：根据输入的内容进行识别，调制一杯饮品。确认后付费，取消输入不扣金币。
- **离开**：继续前行。

输入框每5秒轮换一条饮品建议；玩家输入时不会改动已写的文字。可以输入普通饮料，也可以输入药水图鉴中的名字。

指定图鉴药水时，保留原药水效果，再加入1～2项可好可坏的额外效果。指定复活效果时，额外加入两条负面效果。未识别药效的饮品仍会调制，倾向对自己不利或强化敌人的效果，也可能混入正面收益。

偶尔会发生掉血、获得诅咒或赠送一次免费重做的事故。药水栏已满时会保留已经调好的同一杯，腾出位置后可领取。

甜味、苦味、酸味、辣味、咸味、清凉、麻味、涩味、鲜味、怪味

### 感觉

浪漫的、忧伤的、愤怒的、优雅的、美妙的、奇特的、疯狂的、宁静的、恐怖的、兴奋的、疲惫的、孤独的、绝望的、充满希望的、嫉妒的、怀旧的、梦幻的、诡异的、神圣的、荒诞的、温柔的、残酷的、轻盈的、沉重的

### 浓度

稀薄、淡味、适中、浓味、特浓、超浓

## 分支选项

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。

| 选项 | 效果 |
| --- | --- |
| 领取饮料 | 领取已经做好的饮料。 |
| 离开 | 离开咖啡机。 |
