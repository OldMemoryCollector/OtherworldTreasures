# 不死人的原素瓶

[首页](Home.md) / [遗物图鉴](Relics.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_RELIC_ASHEN_FLASK.webp" width="96" alt="不死人的原素瓶">

**稀有度：**先古

## 效果

移除1个药水栏。右键点击遗物恢复15%最大生命值，可使用2次。篝火处注火可提升1上限并回复所有次数。击败精英或Boss后有50%几率补充1次使用次数。

## 轶闻

> 自古以来，不死人总是在营火间穿梭，而原素瓶也一直随之旅行。
