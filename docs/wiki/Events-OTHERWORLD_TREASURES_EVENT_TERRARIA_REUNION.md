## 奖励规则

从当前可选且尚未持有的饰品中随机展示三件，玩家选择一件。圣骑士护盾只在多人局进入候选；十字章护身符是较低概率出现的隐藏候选。

[十字章护身符](Relics-OTHERWORLD_TREASURES_RELIC_CROSS_NECKLACE.md)、[甜蜜倒刺](Relics-OTHERWORLD_TREASURES_RELIC_HONEY_THORNS.md)、[神话护身符](Relics-OTHERWORLD_TREASURES_RELIC_MYTHIC_CHARM.md)、[圣骑士护盾](Relics-OTHERWORLD_TREASURES_RELIC_PALADIN_SHIELD.md)、[孢子囊](Relics-OTHERWORLD_TREASURES_RELIC_SPORE_SAC.md)、[十字项链](Relics-OTHERWORLD_TREASURES_RELIC_TERRARIA_CROSS_NECKLACE.md)。

## 分支选项

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。

| 选项 | 效果 |
| --- | --- |
| 离开 | 继续前进。 |
| 神话护身符 | 取回【神话护身符】。 |
| 孢子囊 | 取回【孢子囊】。 |
| 十字章护身符 | 取回【十字章护身符】。 |
| 圣骑士护盾 | 取回**圣骑士护盾**。 |
| 十字项链 | 取回**十字项链**。 |
| 甜蜜倒刺 | 取回**甜蜜倒刺**。 |
