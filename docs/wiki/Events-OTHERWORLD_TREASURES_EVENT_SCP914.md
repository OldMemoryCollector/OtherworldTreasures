## 出现条件

| 项目 | 规则 |
| --- | --- |
| 出现层数 | 仅第二幕 |
| 出现位置 | 普通问号事件，无固定的小楼层或房间序号。 |
| 前置条件 | 本局尚未遇见本事件，且队伍至少一名玩家拥有可加工卡牌或任意一件遗物；遇过「旧忆收藏家」后仍可出现。 |
| 重复限制 | 本局至多遇见一次。 |

**选项可用条件：**所有持有的遗物均可投入，包括初始、普通、罕见、稀有、商店、事件、先古及无稀有度遗物；已耗尽、蜡化、熔化、拾取即生效和带宠物的遗物也可投入。未分类品质按普通档加工。只在确认加工时检查所选遗物仍由玩家持有。卡牌须可移除，带永恒的诅咒也可投入，并且稀有度属于加工阶梯；金币在加工时检查，不影响事件入池。

层数按第一、第二、第三幕计算；满足条件表示可以进入候选，不保证本幕一定遇见。

SCP-914静静伫立在眼前：数吨重的发条装置，八百万个铜与锡的零件在机壳深处嗡嗡转动。标注着「输入」与「输出」的两个大隔间由一根铜管连到机身，中间的旋钮上，箭头正对着「1:1」。

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。
