# SCP-914：万能精炼机

[首页](Home.md) / [事件图鉴](Events.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_EVENT_SCP914.webp" width="800" alt="SCP-914：万能精炼机">

SCP-914静静伫立在眼前：数吨重的发条装置，八百万个铜与锡的零件在机壳深处嗡嗡转动。标注着「输入」与「输出」的两个大隔间由一根铜管连到机身，中间的旋钮上，箭头正对着「1:1」。

## 分支选项

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。

| 选项 | 效果 |
| --- | --- |
| 返回 | 返回事件选项。 |
| 投入卡牌 | 从牌组里挑一张卡牌。 |
| 投入遗物 | 点击顶部遗物栏里的一件遗物。 |
| 离开 | 关掉机器，继续前进。 |
| 1:1 | 50金币。将物品转换成同品质的物品。有概率降级，品质过低的物品会损毁。 |
| 精加工 | 120金币。将物品精加工为更高品质的东西，有概率品质不变。 |
| 超精加工 | 200金币。将物品进行超精加工，物品品质会极大提升，但大概率直接损毁，请谨慎选择。 |
| 重新选择 | 返回选择投入物。 |
