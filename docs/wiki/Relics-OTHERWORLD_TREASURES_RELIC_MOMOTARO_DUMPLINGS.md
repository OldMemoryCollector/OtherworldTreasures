# 桃太郎丸子

[首页](Home.md) / [遗物图鉴](Relics.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_RELIC_MOMOTARO_DUMPLINGS.webp" width="96" alt="桃太郎丸子">

**稀有度：**99

## 效果

拥有3颗丸子。右键点击后选择1名敌人收服：普通怪物当前生命低于10、精英怪物当前生命低于15时可以收服，首领无法收服。被收服的敌人会在本场战斗立即死亡；从下一场战斗开始，它以随从的身份登场：生命上限变为原怪的80%（普通怪物）或60%（精英怪物），并回满血。它会保留原本的招式与意图为你作战，造成的伤害减少50%，无法被治疗，死亡后永久消失。

## 轶闻

> 哆啦A梦的道具之一。桃太郎用来收服同伴的丸子，给动物吃下，它就会对你言听计从。
