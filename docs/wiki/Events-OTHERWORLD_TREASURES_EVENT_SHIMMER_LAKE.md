# 微光湖

[首页](Home.md) / [事件图鉴](Events.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_EVENT_SHIMMER_LAKE.webp" width="800" alt="微光湖">

幽暗的洞穴里，一片微光如湖水般荡漾。投入湖中的事物，似乎都将以另一种形态归来。

## 出现与玩法

第二幕进入事件池，尚未遇见时第三幕仍可出现；整局不会重复遇见。生命水晶和生命果分别提供额外遇见机会。

- **微光嬗变**：生命水晶→活力水晶，生命果→神盾果。水晶分支失去一颗生命水晶及10点生命上限；生命果分支消耗一颗生命果。
- **微光转变**：选择一张卡牌，变为同品质的其他卡牌。
- **微光拆解**：将一张牌的升级与附魔转移到另一张适配的可附魔卡牌上。
- **离开**：继续前行。

## 分支选项

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。

| 选项 | 效果 |
| --- | --- |
| 微光嬗变 | **生命水晶**→**活力水晶**，**生命果**→**神盾果** |
| 微光转变 | 选择1张牌，进行**同品质变化**。 |
| 微光拆解 | 将**升级**与**附魔**转移到另一张可附魔的牌。 |
| 离开 | 保留所有物品。 |
| 投入生命水晶 | 失去1颗**生命水晶**和10点生命上限，获得**活力水晶**。 |
| 投入生命果 | 失去1颗**生命果**，获得**神盾果**。 |
| 返回 | 重新考虑湖边的选择。 |
