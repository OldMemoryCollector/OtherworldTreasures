# 湖中剑

[首页](Home.md) / [事件图鉴](Events.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_EVENT_SWORD_IN_THE_LAKE.webp" width="800" alt="湖中剑">

你来到一片宁静的湖泊。腰间的剑忽然发出微弱的光芒。<br>
<br>
湖面泛起涟漪，一位神秘的女子缓缓浮现。<br>
<br>
「你手中的剑，似乎还隐藏着真正的力量。你愿意唤醒它吗？」

## 分支选项

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。

| 选项 | 效果 |
| --- | --- |
| 离开 | 保留原有遗物。 |
| 接受祝福 | 将【石之剑】转化为**【誓约胜利之剑】**。 |
| 唤醒圣剑 | 将【玉之剑】转化为**【真·誓约胜利之剑】**。 |
