## 出现条件

| 项目 | 规则 |
| --- | --- |
| 出现层数 | 仅第二幕 |
| 出现位置 | 普通问号事件，无固定的小楼层或房间序号。 |
| 前置条件 | 本局尚未遇见本事件，且队伍至少一名玩家持有玉之剑，或精英胜利进度为0～2次的石之剑。进度达到3次及以上、尚未进化的石之剑不满足条件，避免提前截断原版进化路线。遇过「旧忆收藏家」后仍可出现。 |
| 重复限制 | 本局至多遇见一次。 |

**选项可用条件：**当前玩家的石之剑进度为0～2次时可选择转化为誓约胜利之剑；玉之剑可选择觉醒为真·誓约胜利之剑。3次及以上的石之剑不显示转化选项，即使队友持有玉之剑使事件入池也是如此。原版石之剑战胜5次精英后进化为玉之剑的规则保留。

层数按第一、第二、第三幕计算；满足条件表示可以进入候选，不保证本幕一定遇见。

你来到一片宁静的湖泊。腰间的剑忽然发出微弱的光芒。<br>
<br>
湖面泛起涟漪，一位神秘的女子缓缓浮现。<br>
<br>
「你手中的剑，似乎还隐藏着真正的力量。你愿意唤醒它吗？」

## 分支选项

不同页面的同名选项属于不同分支，并不同时出现。实际奖励与数量以本次事件预览为准。

| 选项 | 效果 |
| --- | --- |
| 离开 | 保留原有遗物。 |
| 接受祝福 | 将【石之剑】转化为**【誓约胜利之剑】**。 |
| 唤醒圣剑 | 将【玉之剑】转化为**【真·誓约胜利之剑】**。 |
