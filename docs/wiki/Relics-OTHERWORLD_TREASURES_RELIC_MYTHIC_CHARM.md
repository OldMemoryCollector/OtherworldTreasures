# 神话护身符

[首页](Home.md) / [遗物图鉴](Relics.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_RELIC_MYTHIC_CHARM.webp" width="96" alt="神话护身符">

**稀有度：**先古

## 效果

战斗开始时获得1层**缓冲**和1层**人工制品**。每回合开始时恢复1点生命值，当前生命值低于上限一半时改为恢复2点。

## 轶闻

> 来自泰拉瑞亚的配饰，在塔里它带给你自然恢复的力量。
