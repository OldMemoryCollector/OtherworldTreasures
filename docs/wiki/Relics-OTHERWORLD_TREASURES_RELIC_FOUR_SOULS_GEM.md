# 四魂之玉

[首页](Home.md) / [遗物图鉴](Relics.md)

<img src="https://raw.githubusercontent.com/OldMemoryCollector/OtherworldTreasures/main/docs/wiki/images/OTHERWORLD_TREASURES_RELIC_FOUR_SOULS_GEM.webp" width="96" alt="四魂之玉">

**稀有度：**先古

## 效果

相传能实现持有者的愿望，也会让持有者的力量大涨。取得时会因未知原因破碎，化作**四魂之玉碎片**，并使地图上除Boss之外的敌人也带上碎片。

## 轶闻

> 数百年前，巫女翠子夺走大妖怪的魂魄，与自己的灵魂一同释出，只余下这颗魂的结晶。翠子与妖怪的争斗，至今仍在玉中永无休止。
